## Notes

- **Don't pitch the same story to competing journalists in the same publication.** Pick one Atlantic writer, one Wired writer, etc.
- **Lead with the data, not the dashboard.** Reporters care about findable claims, not nice UIs. (Show the UI in follow-up.)
- **Have a ready 1-paragraph blurb for each major angle** so you don't have to write fresh prose for each pitch. The tweetable-insights.md file is the source for these.
- **Track responses in a simple spreadsheet** — name, outlet, status, last contact date.
- **For people who reply but don't run the story**: thank them, ask if there's a colleague who might be a fit. Keep doors open.
